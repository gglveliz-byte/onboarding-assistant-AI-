### 2.3. Reglas de Borde Congeladas para las Partes 3 a 16

1. **Prohibido leer `process.env`** fuera de `src/config/env.dotenv-loader.ts`: usar siempre `getEnvConfig()`.
2. **Prohibido usar `z.coerce.boolean()`**: `Boolean('false') === true`. Usar siempre `booleanFromEnvironmentSchema()`.
3. **Prohibido `node:crypto` directo** en módulos de negocio: usar siempre `CryptoUtils`.
4. **Prohibido aritmética flotante** para dinero o minutos: usar siempre `DecimalMath` (enteros escalados con `BigInt` a 6 decimales).
5. **Prohibido `new Pool()` de `pg`** fuera de `RlsDatabasePool`: las consultas de negocio deben viajar dentro de una transacción con contexto RLS.
6. **Prohibido importar valores de `domain-error.catalog.ts` desde `app-error.ts`**: la cadena debe ser unidireccional (`app-error` ← `domain-error.catalog` ← `result-and-errors`) para evitar ciclos de inicialización.
7. **Prohibido duplicar el migrador**: el único orquestador es `src/shared/infrastructure/database/migrator.ts`.
8. **SuperAdmin de plataforma:** la autoridad es `users.is_platform_superadmin`, **no** `memberships.role` (el esquema prohíbe el rol `SUPERADMIN` dentro de una organización mediante `chk_no_tenant_superadmin`).
9. **Claves EdDSA:** Base64 de una línea (PKCS#8 privada, SPKI pública); obligatorias cuando `NODE_ENV=production`.
10. **Pruebas de RLS:** cualquier prueba de aislamiento debe conectarse con un rol **sin** el atributo `BYPASSRLS`; de lo contrario da un falso positivo garantizado.

Si el autoloader le pasa el enrutador HTTP, el compilador lo rechaza; si ignora el valor devuelto, **el gobierno no podrá cortar sesiones de voz** porque nadie habrá registrado las sesiones vivas. El entrypoint del pool de voz debe conservar ese adaptador y llamar a `registerLiveSession()` por cada sesión abierta.
>
> **D. El orden de arranque YA NO es una dependencia frágil.** `registerVoiceGatewayModule()` resolvía `DI_TOKENS.BillingDeductionPort` de forma anticipada, lo que ataba el arranque a que el Módulo 04 se registrara antes y obligaba a afirmar el tipo con `as never`. Se sustituyó por **`createLazyBillingPort(container)`**, que resuelve el puerto en la **primera llamada real** y falla con un mensaje que nombra `registerBillingWhopModule()`. Aun así, registrar el Módulo 04 antes que el 05 hace que el diagnóstico de arranque sea inmediato.
>
> **E. Verificación obligatoria de los `DI_TOKENS`:** el autoloader debe comprobar con `container.has(token)` que los 18 tokens tengan implementación antes de aceptar tráfico. `container.get()` lanza `InternalError` con el texto «Verifique que el manifiesto del modulo correspondiente se ejecuto antes de resolverlo». Para el diagnóstico de arranque existe además `hasBillingPort(container)`, que comprueba la cadena de cobros **sin instanciarla**.

- **Resumen Técnico:**
  1. **Codec de tramas con byte de tipo (`voice-frame.protocol.ts`):** un byte distingue el audio del usuario final (`0x01`) del control JSON (`0x02`). El audio viaja como binario crudo en lugar de Base64 —que lo inflaría un 33 %— y el audio del asistente viaja **sin cabecera** porque es la ruta caliente. Un fragmento de audio puede llegar partido en dos paquetes, y tratarlo como trama completa incrustaría el byte de cabecera en medio del audio. La prueba verifica la reconstrucción **byte a byte** con tramas partidas, entregadas de una en una, y tres tramas en un mismo paquete.   3. **Reconocimiento de límites JSON con llaves y comillas dentro de cadenas:** el detector de fin de objeto respeta el estado de cadena y los escapes.   5. **Cascada de selectores conservadora:** el selector validado por el mapa, después el atributo `data-oa-key` y por último el identificador. Deliberadamente **no** se recurre a coincidencias por texto visible, que engancharían elementos equivocados en cuanto el copy cambie.
